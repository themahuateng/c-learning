# 第 1 课：第一个 C 程序 —— Hello, World!

## 1. 什么是 C 语言？
C 语言是一种**高级编程语言**，1972 年由丹尼斯·里奇（Dennis Ritchie）在贝尔实验室发明。
- 运行速度快、贴近硬件，被用来写操作系统（如 Linux、Windows 内核的一部分）
- 几乎所有主流语言（Java、Python、Go 等）的底层都是用 C/C++ 实现的
- 学好了 C，你会真正理解"计算机是怎么工作的"

## 2. 代码是怎么变成程序的？
我们写的是**源代码**（人能读懂的文本），计算机只认识**机器码**（0 和 1）。
中间的翻译工作由**编译器**完成：

```
源代码 hello.c  ──gcc 编译──▶  可执行文件 hello.exe  ──运行──▶  屏幕输出
```

这就是为什么我们要先装 GCC —— 它就是那个"翻译官"。

## 3. 程序结构（先记住这个框架）
```c
#include <stdio.h>      // 1. 引入需要用到的"工具箱"（头文件）

int main(void)          // 2. 主函数：程序入口，必须有且只有一个
{
    // 3. 在这里写你的代码
    return 0;           // 4. 返回 0，告诉系统"我正常结束了"
}
```

## 4. 逐行讲解 hello.c

| 代码 | 含义 |
|------|------|
| `#include <stdio.h>` | 引入"标准输入输出"头文件。`printf` 的声明就在这里，不引入就无法使用 |
| `int main(void)` | 定义主函数。`int` 表示函数会返回一个整数，`void` 表示不需要接收参数 |
| `{ ... }` | 函数体，用一对大括号包起来 |
| `printf("Hello, World!\n");` | 调用 printf 函数，把引号里的内容打印到屏幕；`\n` 是换行符 |
| `return 0;` | 返回 0，代表程序正常结束 |

## 5. 怎么编译和运行？
方法一（VS Code 快捷键）：
1. 打开 `hello.c`
2. 按 `Ctrl + Shift + B` 编译
3. 在终端输入 `.\hello.exe` 运行（或按 `F5` 调试）

方法二（手动在终端）：
```
gcc hello.c -o hello.exe
.\hello.exe
```

## 6. 动手练习（一定要亲手做！）
1. 把 `"Hello, World!"` 改成你自己的名字，编译运行。
2. 在下面再加一行 `printf`，输出一句你喜欢的名言。
3. 试试把 `return 0;` 删掉再编译，观察编译器给你的警告信息。
4. 试试把 `\n` 删掉，多运行几次，观察输出有什么变化。

> 💡 小提示：`//` 是单行注释，`/* ... */` 是多行注释。注释是写给人看的，编译器会忽略它们。
