# 第 2 课：变量和数据类型

## 1. 什么是变量？
变量 = **内存里一个带名字的小盒子**，用来存数据，可以随时放新值、取出来用。

```
int age = 20;
 │    │    │
 │    │    └─ 初始值（可省略，但建议写）
 │    └─ 变量名（自己起，见命名规则）
 └─ 类型（决定盒子多大、能装什么）
```

## 2. 基本数据类型（重点记忆）

| 类型 | 中文名 | 大小 | 取值范围 | 示例 |
|------|--------|------|---------|------|
| `int` | 整数 | 4 字节 | 约 -21亿 ~ 21亿 | `int a = 100;` |
| `float` | 单精度小数 | 4 字节 | 约 7 位有效数字 | `float f = 3.14f;` |
| `double` | 双精度小数 | 8 字节 | 约 15 位有效数字 | `double d = 3.14159;` |
| `char` | 单个字符 | 1 字节 | -128 ~ 127 | `char c = 'A';` |
| `_Bool` | 布尔（真/假） | 1 字节 | 0 或 1 | `_Bool ok = 1;` |

其他：`short`（2字节整数）、`long`（长整数）、`unsigned`（无符号，只能存正数）。

## 3. printf 格式符（输出）

| 格式符 | 对应类型 | 示例 |
|--------|---------|------|
| `%d` | int | `printf("%d", 100);` |
| `%f` | float | `printf("%.2f", 3.14);` |
| `%lf` | double | `printf("%lf", 3.14);` |
| `%c` | char | `printf("%c", 'A');` |
| `%s` | 字符串 | `printf("%s", "hi");` |
| `%zu` | sizeof 的结果 | `printf("%zu", sizeof(int));` |

`%.2f` 的 `.2` = 保留 2 位小数；`%.10lf` = 保留 10 位。

## 4. scanf 从键盘输入

```c
int age;
scanf("%d", &age);   // 注意：age 前面有 & ！
```

- `&` 是"取地址"运算符。scanf 需要知道把数据存到内存的哪个位置，所以必须加 `&`。
- 原理在第 4 课学指针时会彻底讲清楚，现在先记住：**scanf 读变量必须加 `&`**。

## 5. 常量：值不能变的量

```c
#define PI 3.14159      // 方式一：编译时替换（没有分号）
const int DAYS = 7;     // 方式二：const 修饰（有分号，更安全，推荐）
```

## 6. 变量命名规则
- 只能由字母、数字、下划线组成，且**不能以数字开头**
- 不能是关键字（如 int、return、if）
- 习惯用英文小写，多个单词用下划线：`your_age`、`max_score`
- 见名知意！`age` 比 `a` 好，`total_score` 比 `t` 好
