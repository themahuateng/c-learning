# 第 4 课：循环（让程序重复干活）

## 1. while 循环（先判断后执行）
    while (条件) {
        语句;
    }
    只要条件为真，就一直执行
    ★ 别忘了在循环体里更新变量，否则死循环！

## 2. for 循环（最常用，"三合一"）
    for (初始化; 条件; 更新) {
        语句;
    }
    例：for (int i = 1; i <= 100; i++) { ... }
    执行顺序：初始化 → 判断 → 执行 → 更新 → 判断 → 执行 → ...
    特点：初始化/条件/更新都写在开头，一目了然

## 3. do-while（先执行后判断，至少执行一次）
    do {
        语句;
    } while (条件);
    ★ 注意末尾有分号！

## 4. break 和 continue
    break    → 立刻跳出整个循环（循环结束）
    continue → 跳过本次循环的剩余部分，直接进下一次

## 5. 两个经典陷阱
    ① 死循环：while (1) 或忘了更新变量 → 程序卡死
    ② 差一错误（off-by-one）：<= 还是 < 要算清
       for (int i = 1; i <= 5; i++)  → 5 次（1,2,3,4,5）
       for (int i = 1; i < 5; i++)   → 4 次（1,2,3,4）
    验证方法：数一数循环体执行了几次

## 6. 累加求和套路（练习1要用）
    int sum = 0;              // 先准备一个空的"收纳盒"
    for (int i = 1; i <= 100; i++) {
        sum = sum + i;        // 把 i 装进收纳盒
    }
