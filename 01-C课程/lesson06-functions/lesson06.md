# 第 6 课：函数（代码的"打包"）

## 1. 为什么要有函数？
把重复的代码打包成"零件"，一次定义、到处调用
也是拆解大问题的基本方法（模块化）

## 2. 函数长什么样
    返回类型 函数名(参数列表) {
        函数体;
        return 返回值;
    }
    例：double add(double x, double y) { return x + y; }
        └─返回类型     └──参数（喂进去的数据）──┘

## 3. 调用函数
    double r = add(3.5, 2.5);
    实参(3.5, 2.5) → 传给 形参(x, y)

## 4. 参数传递 = 值传递（复制）
    函数拿到的是参数的"副本"，在函数里改形参，不影响外面的变量

## 5. 返回值 return
    return 值;   // 把结果交回给调用者
    void 类型    // 表示"没有返回值"（只干活不回话）

## 6. 函数原型（先声明后用）
    main 在函数之前时，要先声明原型（分号结尾）：
    double add(double x, double y);   // 只声明不实现

## 7. 递归 = 函数调用自己
    必须有 2 部分：
    ① 结束条件（否则无限递归 → 栈溢出崩溃）
    ② 调用自己（规模要变小）
    例：阶乘
    int factorial(int n) {
        if (n <= 1) return 1;             // 结束条件
        return n * factorial(n - 1);      // 自己调用自己
    }
