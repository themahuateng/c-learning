# 第 10 课：字符串与指针

## 1. 两种写法，一个致命区别

    char s1[] = "hello";      // 数组：自己有一份 6 个格子，内容可以改
    char *s2  = "hello";      // 指针：指向一份"不许动"的常量，内容不能改

    s1[0] = 'H';    // ✅ 合法：改自己那份
    s2[0] = 'H';    // ❌ 运行时会崩：改的是只读区域

**怎么记**：数组是"自己抄了一份"；指针是"指着一份贴在墙上、不许改的原文"。

> 编译器一般不会拦你，是运行到那一行才崩——这是 C 里最经典的坑之一。

## 2. 字符串的本质

就是一串 `char`，以 `'\0'` 结尾。

数组名和字符指针都是"首地址"，所以 `char *` 可以指向字符串的任意位置：

    char *p = s1;        // 指向 'h'
    char *q = s1 + 1;    // 指向 'e'
    printf("%s", q);     // 输出 "ello"

## 3. 遍历字符串的两种写法

    /* 下标法 */
    for (int i = 0; s1[i] != '\0'; i++) { ... }

    /* 指针法（更"老 C"） */
    for (char *q = s1; *q != '\0'; q++) { ... }

两种完全等价，第二种就是第 7 课学的"指针 + 1 跳到下一个元素"。

## 4. 字符串作函数参数

    int  my_strlen(const char *s);                  // 只读，用 const
    void my_strcpy(char *dst, const char *src);     // dst 要改，src 只读

`const` 是"承诺我不改它"，加上它编译器会帮你抓错，是个好习惯。

## 5. 字符指针数组（字符串列表）

    char *names[] = {"Tom", "Jerry", "Spike"};
    names[0]  →  "Tom"
    names[1]  →  "Jerry"

每个元素是一个 `char *`，也就是一个字符串。

**这就是 `char *argv[]` 的结构**——你在第 7 课见过的命令行参数，用的正是这个。

## 6. `char **` 是什么

指向"`char *`"的指针 = 指针的指针。

    char *argv[]   ≡   char **argv      （在函数参数位置，两者等价）

什么时候需要它？当你要**改一个指针本身**（而不只是改它指的内容）时。
现在知道有这回事就行，平时用 `char *argv[]` 那种写法更清楚。

## 7. 标准库函数（了解即可，不用自己写）

都在 `<string.h>` 里：

| 函数 | 干什么 |
|---|---|
| `strlen(s)` | 字符串长度（不含 `\0`）|
| `strcpy(d, s)` | 复制 |
| `strcmp(a, b)` | 比较（0 = 相等）|
| `strcat(d, s)` | 拼接 |

学这一课的意义是：**知道它们内部是怎么实现的**（就是下面练习里你自己写的那些）。

## 8. 常见坑

- `char *s = "hi"; s[0] = 'H';` → 运行时崩
- 忘了结尾的 `'\0'`，后面打印出一堆乱码
- `strcpy` 目标空间不够 → 缓冲区溢出（危险！）
- 用 `==` 比较字符串内容 → **比较的是地址**，要用 `strcmp`
