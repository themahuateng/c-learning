# C 实践题库

> 用途：补足 LeetCode 函数题无法覆盖的 C 语言完整程序能力。  
> 每题都是本地 C 程序，必须处理输入、输出、错误和内存。  
> 状态：候选 → 待训练 → 已训练 → 已掌握。

## 使用规则

1. 先做 C-P01~C-P04，再谈复杂结构。
2. 每个任务必须有一个 `main`，不能只写一个孤立函数。
3. 动态内存题必须检查 `NULL`，并 `free` 后置 `NULL`。
4. 文件题必须处理打开失败和空文件。
5. 调试题不要先看答案，先写“我怀疑哪里、如何验证”。
