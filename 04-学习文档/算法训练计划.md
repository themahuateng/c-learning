# 算法训练计划

> **这是主线的算法练习层，不是第二条学习线。**  
> **2026-11-01 调整：算法训练不单独设置 stage，不改变主线的“结构体验收 → 链表 → 栈/队列 → 文件项目”顺序。**
> 只在当前 C 主线任务完成后，按 `主线.md` 插入对应算法练习。

> 目标：不是“会写代码”，而是能独立完成：读题 → 建模 → 设计 → 证明 → 复杂度 → 测试。
> 语言：先用 C 手写，不依赖现成库；数据结构阶段从零实现。后期用 Python 复写。
> 原则：一次只练一个主题；讲一个、练一个；代码跑通不算过关。
>
> 范围：本计划只覆盖“算法基础线”。数据结构线仍在 C 第 14 课后启动。
> 顺序：按先修关系推进，不硬卡周次；当前从数组 + 排序开始。
> 配套：`算法题目清单.md`、`算法题库/README.md`、`算法题库/核心题群-数组与基础算法.md`、`算法题库/测试与验收模板.md`、`C实践题库.md`、`资源与工具总表.md`、`课程一致性审计.md`。

## 一、训练闭环

每道题固定走五步：

1. **读题**：输入、输出、约束、边界
2. **手算**：正常例、边界例、反例
3. **设计**：暴力思路 → 优化，写清不变量
4. **编码**：先伪代码，再 C
5. **验收**：按 `算法题库/测试与验收模板.md` 做测试、复杂度、证明和复盘

## 五、过关标准

一道题必须同时满足：

- 不看答案能独立写出来
- 能说清时间复杂度和空间复杂度
- 能说出核心不变量
- 能通过边界测试
- 能改一个条件做出变式
