# 核心题群：数组与基础算法

> 用途：当前阶段的训练顺序和深度要求。  
> 规则：一次只开一个题群；题群内部按 D0→D5 推进。  
> 这里写“做什么、验收什么”，不直接写完整答案。

## 使用方式

每道题先只做三件事：

1. 用自己的话复述题面；
2. 手算正常例、边界例、反例；
3. 说出暴力解法和想优化的方向。

三步没完成，不进入编码。

## S01 选择排序：从“会背”到“能证明”

**先修**：数组、for 循环、比较、交换、下标。

**题源**：C4 课件例 4.5（选择法从大到小排序）；LC 912（排序数组，后续再用）。

### 题目簇

1. **跟踪题**：给 `[5, 1, 4, 1, 3]`，画出每一轮结束后数组的样子。
2. **实现题**：写升序选择排序。
3. **改条件**：改成降序。
4. **找错题**：交换语句误放进内层循环，找出错误并解释。
5. **复杂度题**：分别数比较次数和交换次数。
6. **迁移题**：用结构体数组按成绩排序，成绩相同如何保持原顺序？

### 必须自己发现的边界

- 空数组和只有一个元素；
- 已经有序；
- 完全逆序；
- 有重复值；
- 负数；
- `n - 1` 与 `n` 的边界。

### 验收问题

- 每轮结束后，数组的哪一段一定有序？
- `k` 在内层循环开始前、结束后分别表示什么？
- 为什么外层只走到 `n - 1`？
- 选择排序稳定吗？如果不稳定，举一个反例。
- 交换次数和比较次数的量级一样吗？
- 如果只允许交换相邻元素，算法会变成什么？

### 过关证据

- 手算表完整；
- 代码通过至少 5 组边界测试；
- 能指出“交换块放错层”的后果；
- 能解释复杂度和稳定性；
- 能改出降序版本。

## S02 冒泡、选择、插入：不是三个名字，是三种不变量

**先修**：S01 完成。

**题源**：C4 课件例 4.4、4.5、4.6。

### 题目簇

1. 用同一组数据分别跟踪三种排序；
2. 比较每轮结束后的有序区域；
3. 统计比较次数和交换次数；
4. 判断稳定性；
5. 在“几乎有序”的数据上选一个更合适的算法；
6. 写一个统一测试函数，验证三个版本的输出相同。

### 必须能回答

- 冒泡排序每一轮把哪个元素送到最终位置？
- 选择排序每一轮为什么只交换一次？
- 插入排序的“已排序部分”在哪里？
- 哪种排序在已经有序时最占便宜？
- 为什么不能只凭“跑得快”判断算法，而要看输入规模和数据形态？

### 过关证据

- 能画出三种算法的不变量；
- 能用手算表说明差异；
- 不能把三者都写成同一段代码；
- 能根据数据特点选择算法。

## S03 二分查找：区间定义必须唯一

**已核验题源**：LC 704。

### 题目簇

1. 手算 `nums = [-1,0,3,5,9,12]`，分别查找 `9` 和 `2`；
2. 用“闭区间”写法实现；
3. 用“左闭右开”写法实现；
4. 找出两种写法中 `while`、`mid`、边界更新的差异；
5. 变形：查找插入位置（LC 35）；
6. 变形：查找第一个和最后一个位置（LC 34）；
7. 变形：整数平方根（LC 69）。

### 不变量

闭区间写法必须能说清：

```text
答案如果存在，一定还在 [left, right] 这个区间里
```

每次更新后，这个条件不能丢。

### 必须自己发现的边界

- 目标在第一个位置；
- 目标在最后一个位置；
- 目标不存在，且小于所有元素；
- 目标不存在，且大于所有元素；
- 单元素数组；
- 有重复元素时，普通二分找到的不一定是第一个。

### 验收问题

- 为什么不能把 `while` 条件和边界更新各写各的？
- `left <= right` 和 `left < right` 分别对应什么区间？
- `mid` 为什么可能溢出？C 中怎样写更稳？
- 704 通过后，为什么不能直接拿同样的代码做 34？
- 二分的时间复杂度为什么是 `O(log n)`，空间复杂度为什么是 `O(1)`？

## S04 原地删除：保持什么，丢弃什么

**已核验题源**：LC 27、LC 26、LC 283。

### 题目簇

1. LC 27 删除指定值；
2. LC 26 删除有序数组重复项；
3. LC 283 移动零；
4. 比较“保持相对顺序”和“允许改变顺序”的差异；
5. 自己写一个“原地压缩数组”的通用函数。

### 不变量

必须能写出类似这样的区间含义：

```text
[0, k) 是已经保留的元素
[k, i) 是已经处理过、可以丢弃的元素
i 是当前正在检查的位置
```

### 必须自己发现的边界

- 全部都要删除；
- 一个都不用删除；
- 空数组；
- 目标值在开头、中间、结尾；
- 有连续重复值。

### 验收问题

- 题目只要求返回 `k`，为什么还要改数组？
- 不保持顺序时能否少写一些交换？
- 为什么不能一边遍历一边随意覆盖还没读到的元素？
- 代码通过后，原数组 `k` 后面的内容有定义吗？

## S05 双指针：左右指针和快慢指针不是一回事

**已核验题源**：LC 344、LC 125、LC 977、LC 167。

### 题目簇

1. LC 344 原地反转字符数组；
2. LC 125 忽略非字母数字后判断回文；
3. LC 977 有序数组平方；
4. LC 167 有序数组两数之和；
5. 自己画图区分“相向移动”和“同向追赶”。

### 不变量

- 反转：`[0, left)` 和 `(right, n-1]` 已经处理完；
- 回文：当前左右字符还没比较；
- 平方：未处理区间的两端一定包含当前最大平方值；
- 两数之和：根据和的大小只会排除一端。

### 必须自己发现的边界

- 长度为奇数/偶数；
- 空字符串、全标点字符串；
- 重复值；
- 负数；
- 两个数正好是同一个下标时是否允许。

### 验收问题

- 为什么反转循环用 `left < right` 而不是 `left <= right`？
- 回文题里字符过滤和指针移动的先后顺序为什么重要？
- 977 为什么能从两端选较大平方，而不是从中间开始？
- 167 中 `sum < target` 时为什么只能移动左指针？

## S06 滑动窗口：窗口里到底维护了什么

**已核验题源**：LC 209。

### 题目簇

1. 手算 `target = 7, nums = [2,3,1,2,4,3]`；
2. 写暴力枚举所有子数组；
3. 找到“正数数组”带来的单调性；
4. 写滑动窗口；
5. 加一个测试：没有满足条件的子数组时返回什么；
6. 追问：如果允许负数，窗口还能这样收缩吗？

### 不变量

窗口 `[left, right]` 内的和、窗口长度、当前最优答案三者必须同步维护。  
每次移动边界后，都要能说出窗口代表什么。

### 必须自己发现的边界

- 单个元素就满足；
- 全部元素加起来也不满足；
- 目标很小/很大；
- 窗口缩到空；
- 数组长度很大时的溢出风险。

### 验收问题

- 为什么右指针只向右走，不会回退？
- 为什么左指针可以一直向右走？
- 如果数组不全是正数，为什么“缩小窗口只会让和变小”不成立？
- `O(n)` 的依据是什么，不是两层循环吗？

## S07 二维数组：行列、地址和原地旋转

**题源**：C4 课件例 4.7~4.10；LC 48。

### 题目簇

1. 输入/输出一个 `m × n` 矩阵；
2. 求每行和、每列和、主对角线；
3. 矩阵转置；
4. 矩阵乘法；
5. LC 48 顺时针旋转 90°；
6. 比较“新开矩阵”和“原地旋转”的空间复杂度。

### 必须自己发现的边界

- 不是方阵时能不能直接原地旋转；
- `n = 1`；
- 行数和列数不同；
- 循环只走上三角或左半边；
- 交换过程中是否覆盖了还没读取的元素。

### 验收问题

- `a[i][j]` 在内存中前面有多少个元素？
- 转置为什么只交换 `i < j` 的部分？
- 顺时针旋转为什么可以拆成“转置 + 左右翻转”？
- 4 个位置轮换时，临时变量保存的是谁？

## S08 递归：调用栈不是装饰

**题源**：C3 课件递归相关内容；LC 509 作为后续验证。

### 题目簇

1. 手算 `factorial(5)` 的调用链；
2. 标出每一层的参数和返回值；
3. 改写为循环；
4. 找出缺少递归出口或出口错误的后果；
5. 计算递归调用的时间和栈空间；
6. 迁移到斐波那契，观察重复计算。

### 验收问题

- 递归函数在什么时候停止？
- 每一层“交回”的值交给谁？
- 为什么 `factorial(n - 1)` 不能写成 `factorial(n) - 1`？
- 递归深度过大时会发生什么？
- 同一个问题什么时候适合递归，什么时候适合循环？
