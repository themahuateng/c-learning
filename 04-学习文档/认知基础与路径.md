> 这份文档回答三件事：这个世界怎么分层、什么能力不可跳过、从哪条路上去。

## 一、认知基础：计算机世界是怎么分层的

从底到顶，一共八层：

```
第 8 层  研究与影响     提出问题、做出新东西、被别人引用
第 7 层  领域应用       AI / CV / NLP / 系统 / 安全      ← 价值在这里产生
第 6 层  软件工程       测试 / CI / 协作 / 长期维护
第 5 层  编程语言       C / C++ / Python                ← 表达工具
第 4 层  系统          操作系统 / 编译器 / 网络
第 3 层  硬件与体系结构 逻辑门 / CPU / GPU / 内存层次
第 2 层  计算理论       算法 / 复杂度 / 信息论
第 1 层  数学          微积分 / 线代 / 概率 / 离散
```

### 三条关键规律

**1. 越往下，越难、越慢、但越不可替代。**
会调 Python 库的人以百万计；懂 GPU 内存层次、能写 CUDA kernel 的人以万计。

**2. 越往上，越好上手，但可替代性越强。**
"会用 PyTorch 跑个模型"这件事，两周能学会——所以它不值钱。

**3. 最稀缺的不是"会某一层"，而是"能跨越 2~3 层"。**

| 人 | 覆盖的层 | 稀缺度 |
|---|---|---|
| 会调库跑模型 | 第 7 层 | 低 |
| 会写训练代码 + 懂模型数学 | 第 1 + 7 层 | 中 |
| **会改推理引擎 + 懂 GPU + 懂模型** | **第 3 + 4 + 7 层** | **极高（AI Infra 顶尖工程师）** |
| 数学 + 系统 + 领域都能打通 | 第 1 + 4 + 7 层 | 顶尖研究员常见组合 |

**这张表就是"高标准"的真正含义**：不是每层都学一点，而是在某一层扎深，同时能向下看懂两层、向上接住一层。

### 用这个模型看你的位置

- 你现在：第 5 层刚开始（C 语言第 7 课）
- 你的目标（AI 硕士）：至少要到第 7 层用得动，第 1 层站得住
- 你的差异化机会：**第 3~4 层（通信/信号/硬件）+ 第 7 层（AI）** ——这是"通信+AI"交叉方向稀缺的原因

## 二、能力基础：不可跳过的七样

这些是"地基"，越往上走越依赖它们，绕不过去。

### 1. 数学（第 1 层）
**判据**：能自己推一遍梯度下降；能解释为什么要用特征值分解。
不是"学过"，是"能推导"。

### 2. 一门语言到底（第 5 层）
**判据**：能写 1000 行不崩的程序；能读懂别人写的代码。
C 是地基（内存、指针、系统感），Python 是工具（效率、生态）。

### 3. 数据结构与算法（第 2 层）
**判据**：给你一个问题，你能判断"暴力解法能不能过"，以及"该怎么优化"。

### 4. 计算机系统（第 3~4 层）
**判据**：能解释一个 C 程序从源码到跑起来，中间经历了什么（编译、链接、加载、内存布局、系统调用）。

### 5. 抽象能力（贯穿所有层）
**判据**：能把一个现实问题变成"数据结构 + 算法 + 接口"。
这是程序员最核心的能力——比会几门语言重要得多。

### 6. 调试与排查（贯穿）
**判据**：给你一个崩溃的程序 / 慢的接口，你能定位到原因，而不是猜。

### 7. 阅读能力（贯穿）
**判据**：能读英文文档；能读一篇论文的摘要和方法部分；能读别人的代码。

> 这七样之外的一切（框架、工具、某个具体技术），都是**易变的**——三五年换一批。
> 这七样是**不变的**——二十年前的顶尖程序员需要，今天的也需要。

## 三、路径：三条真实的路

### 路线 A：学术路线（科研 / 博士）

**适合**：对"提出问题、做出新东西"上瘾的人。
**路线**：大二进实验室 → 参与课题 → 写论文 → 保研/直博 → 顶会 → 博士 → 研究员/教职。
**关键**：越早进实验室越好；需要一个愿意带你的导师。

### 路线 B：工业路线（工程 / 系统）

**适合**：喜欢"把东西做出来、做得快、做得好"的人。
**路线**：做项目 → 实习 → 大厂或 AI 创业公司 → 后端/系统/AI Infra 工程师。
**关键**：项目复杂度 + 实习经历 + 工程能力（测试、CI、协作）。

### 路线 C：交叉路线（通信 + AI）★ 你的天然优势

**适合**：你——通信工程背景 + AI 目标。
**方向举例**：信号处理 + 深度学习、无线通信 + AI（语义通信、AI 空口）、边缘 AI、AI 芯片。
**为什么稀缺**：懂通信的人大多不会 AI，懂 AI 的人大多不懂通信。
**路线**：本科打好两个基础 → 进相关实验室 → 做交叉方向课题 → 保研时直接瞄准这个方向的导师。

### 关键节点（时间表）

| 时间 | 必须完成的事 |
|---|---|
| 大一 | 编程基础（C）+ 数学跟课 + 工具链（Git/Linux） |
| 大一下 ~ 大二上 | 数据结构与算法 + Python + **进实验室了解科研** |
| 大二下 | 计算机系统 + 确定方向（学术 / 工业 / 交叉）|
| 大三上 | 深度学习 + 一个像样的项目 + 竞赛/科研产出 |
| 大三下 | 实习 / 论文 / 保研夏令营材料 |
| 大四 | 毕设 + 衔接 |

### 最大的三个杠杆

1. **尽早进入"真的做东西"的环境**——实验室、开源社区、实习。
   自己一个人学，天花板是"教程水平"；在有反馈的环境里，天花板是"能做出没人做过的东西"。

2. **找到能 review 你的人**
   这一步最贵也最有效。被人指出"你这段设计有问题"，比自学一个月涨得快。

3. **一个方向做到深，而不是样样会一点**
   招聘和招生看的不是"你学过多少"，是"你在某件事上做到过多深"。

## 四、给你的三句话

1. **认知**你已经拿到——就是这份文档的那张八层图。以后每学一样东西，问自己：它在第几层？我是在向上铺摊子，还是在向下扎根？

2. **能力基础**从第 8 课开始积累——每学完一课，那七样基础就厚一层。不存在"先攒完再开始"。

3. **路径**的关键节点在大二上（进实验室）。你还有一年半时间准备——足够，而且从容。

> 最后一句实话：**"无限接近"的唯一方法是"今天多写一行"。**
> 这份文档给你的是地图，路要自己走。
