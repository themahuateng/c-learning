## 三、统一口径

### 1. 三条线

```text
C 主线：语言、内存、结构体、项目
算法基础线：复杂度、数组/字符串算法、排序、查找、递归
课堂侧线：学校课件与考试例题，限时处理
```

当前阶段**不同时开 Python 和数据结构线**。数据结构线仍按 C 第 14 课后启动。

`学习路线.md` 不再维护“当前下一题”，只保留阶段目标；当前下一题只写在 `LEARNING_STATE.md`。

### 3. 算法基础线与数据结构线的边界

- 算法基础线现在开：数组、字符串、排序、二分、递归、复杂度
- 数据结构线第 14 课后开：链表、栈、队列、哈希、树、图
- 树/图/DP 不提前塞进当前训练

## 四、题目来源原则

不能承诺“知道所有题”，也不能靠记忆编题单。题库必须是：

1. 有明确来源和链接
2. 逐题核验题面、输入输出和约束
3. 映射到知识点
4. 标注难度、先修、状态
5. 记录错因和复杂度

题目状态只允许：

```text
候选 → 待核验 → 已核验 → 已训练 → 已掌握
```

AI 只出变式，不替代主题库。
