# 资源与工具总表

> 目的：以后每个学科都按“主资料 / 题库 / 工具 / skill / MCP / 核验状态”管理，不再随机找资料。
> 日期：2026-10-30

## 一、资源准入规则

1. 优先官方文档、教材、课程主页、原始论文。
2. 每个资源记录来源、版本/日期、适用范围、核验状态。
3. 题库必须逐题核验题面、输入输出、约束和链接。
4. skill/MCP 先看来源、维护状态、权限范围；不装低星、不明来源的自动化工具。
5. 不安装“自动刷题/自动提交/自动生成答案”类工具，避免替代学习过程。

> 当前算法题库服务的是 **C 课程 + 基础算法能力**，不是蓝桥杯或 ACM 专项题库。  
> 蓝桥杯、Codeforces、ACM 题源只作为后续分支，不能和当前基础主线混在一起。

### 本次明确没有找到的东西

- **没有找到可信的算法训练专用 skill。**  
  skills.sh 能打开；当前本机已装 skill 里没有算法教练类 skill。GitHub 上能搜到一些相关仓库，但多数不是可审计的 skill，不能仅凭名字安装。

  这会替代学习过程，不符合当前目标。
- **自定义 MCP 目前不是进度真相源。**  
  它可以读取和检查，但不能替学习者判定“掌握”。

### 题目检索的边界

这次核验了当前题单中的 20 道题，不代表：

- 题库已经完整；
- 每道题的所有边界都已经测试；
- 每道题都能不看答案做出来；
- 以后不会发现新的重要题。

题库的覆盖由 `算法题库/README.md`、`算法题库/核心题群-数组与基础算法.md` 和 `课件例题总清单.md` 共同维护。
