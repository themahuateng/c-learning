# 常用函数速查（先只记这些）

> 目标：先知道“有这个函数、它是干什么的”，细节用到再查。

## 一眼记忆

```text
长、复、拼、比、找
```

| 字 | 函数 | 干什么 |
|---|---|---|
| 长 | `strlen` | 字符串长度 |
| 复 | `strcpy` / `strncpy` | 复制 |
| 拼 | `strcat` / `strncat` | 拼接 |
| 比 | `strcmp` / `strncmp` | 比较，`0` 相等 |
| 找 | `strstr` / `strchr` / `strrchr` | 查找，找不到返回 `NULL` |

带 `n` = 最多处理 `n` 个字符。

## 字符串：`string.h`

| 目的 | 主函数 | 一句话 |
|---|---|---|
| 长度 | `strlen` | 不算 `'\0'` |
| 复制 | `strcpy` / `snprintf` | `snprintf` 更安全 |
| 拼接 | `strcat` / `snprintf` | 接在后面 |
| 比较 | `strcmp` | `0` 表示相等 |
| 查找 | `strstr` | 找不到返回 `NULL` |

带 `n` 的：`strncpy` / `strncat` / `strncmp` = 最多操作 `n` 个字符。

| 函数 | 作用 |
|---|---|

| `pow` | 次方 |
| `fabs` | 浮点数绝对值 |

## `str*` 函数：格式 + 例子

> 都在 `<string.h>` 里。`const char *` 表示只读字符串，`char *` 表示可修改。

### 1. `strlen`：长度

```c
size_t strlen(const char *s);
```

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "hello";

    printf("%zu\n", strlen(s));   /* 5 */
    printf("%zu\n", sizeof(s));   /* 6 */

    return 0;
}
```

`strlen` 不算 `'\0'`；`sizeof` 算。`strlen` 返回 `size_t`，用 `%zu` 打印。

### 2. `strcpy` / `strncpy`：复制

```c
char *strcpy(char *dst, const char *src);
char *strncpy(char *dst, const char *src, size_t n);
```

```c
char dst[10];

strcpy(dst, "hello");
printf("%s\n", dst);   /* hello */
```

危险：`strcpy` 不管目标够不够。

```c
char bad[3];

strcpy(bad, "hello");  /* 越界：需要 6 字节，只有 3 字节 */
```

`strncpy`：

```c
char dst[6];

strncpy(dst, "hello", sizeof(dst) - 1);
dst[sizeof(dst) - 1] = '\0';

printf("%s\n", dst);   /* hello */
```

坑：`strncpy` 最多复制 `n` 个，但 `src` 太长时可能不补 `'\0'`。

更安全的复制：

```c
char dst[6];

snprintf(dst, sizeof(dst), "%s", "hello");
```

### 3. `strcat` / `strncat`：拼接

```c
char *strcat(char *dst, const char *src);
char *strncat(char *dst, const char *src, size_t n);
```

```c
char s[20] = "hello";

strcat(s, " world");
printf("%s\n", s);     /* hello world */
```

`strncat`：

```c
char s[20] = "hello";

strncat(s, " world", 3);
printf("%s\n", s);     /* hello wo */
```

`strncat` 会自动补 `'\0'`，但 `dst` 空间仍要够。

### 4. `strcmp` / `strncmp`：比较

```c
int strcmp(const char *a, const char *b);
int strncmp(const char *a, const char *b, size_t n);
```

```c
printf("%d\n", strcmp("abc", "abc"));  /* 0 */
printf("%d\n", strcmp("abc", "abd"));  /* < 0 */
printf("%d\n", strcmp("abd", "abc"));  /* > 0 */
```

`0` 表示相等。不要用 `a == b` 比较内容。

### 5. `strstr` / `strchr` / `strrchr`：查找

```c
char *strstr(const char *haystack, const char *needle);
char *strchr(const char *s, int c);
char *strrchr(const char *s, int c);
```

```c
char s[] = "hello world";

char *p = strstr(s, "world");
if (p != NULL) printf("%s\n", p);   /* world */

char *q = strchr(s, 'l');
if (q != NULL) printf("%s\n", q);   /* llo world */

char *r = strrchr(s, 'l');
if (r != NULL) printf("%s\n", r);   /* ld */
```

- `strstr`：找子串
- `strchr`：找字符第一次出现
- `strrchr`：找字符最后一次出现
- 找不到都返回 `NULL`

### 6. `strtok`：切分

```c
char *strtok(char *s, const char *delim);
```

```c
char s[] = "a,b,c";
char *p = strtok(s, ",");

while (p != NULL)
{
    printf("%s\n", p);
    p = strtok(NULL, ",");
}
```

输出：

```text
a
b
c
```

注意：`strtok` 会修改原字符串；第一次传 `s`，后面传 `NULL`。

### 7. 不是 `str*`，但最好认识

```c
int snprintf(char *buf, size_t size, const char *fmt, ...);  /* stdio.h，安全组装字符串 */
void *memcpy(void *dst, const void *src, size_t n);          /* 按字节复制 */
void *memset(void *s, int c, size_t n);                     /* 按字节填充 */
int memcmp(const void *a, const void *b, size_t n);          /* 按字节比较 */
```

## `const` 是什么

`const` = 只读（read-only）。它告诉编译器：通过这个名字，我不修改它。

### 1. 普通变量

```c
const int x = 5;
int y = x;     /* 可以读 */
x = 6;         /* 错：不能改 */
```

注意：C 里 `const int n = 5;` 一般不能当 `case` 的常量，也不能当数组长度（除非是 VLA）。

### 2. 指针上的 const（最容易混）

从右往左读：

```c
const char *s;        /* s 是普通指针，指向只读 char；*s 不能改，s 可以改 */
char * const p;       /* p 是只读指针，指向可改 char；*p 可以改，p 不能改 */
const char * const q; /* q 是只读指针，指向只读 char；*q 和 q 都不能改 */
```

例子：

```c
char a[] = "hello";
const char *s = a;   /* 不能通过 s 改字符 */
s = "world";         /* 可以，s 自己可以换指向 */

char b[] = "hello";
char * const p = b;  /* p 不能换指向 */
p[0] = 'H';          /* 可以，改内容 */
```

### 3. 函数参数

```c
int my_strlen(const char *s);               /* 只读，函数不修改字符串 */
void my_strcpy(char *dst, const char *src); /* dst 要写，src 只读 */
```

`const` 是“承诺不修改”，既方便别人读懂，也能让编译器帮你抓错。

### 4. const 和 #define 的区别

| | `const` | `#define` |
|---|---|---|
| 处理阶段 | 编译器 | 预处理 |
| 有类型吗 | 有 | 没有 |
| 有作用域吗 | 有 | 从定义处到文件末尾 |
| 能当 case 常量吗 | C 里一般不能 | 可以 |
| 能调试吗 | 能 | 不能（已经被替换掉） |

实际写代码：

- 需要“有类型的只读变量” → `const`
- 需要“宏常量/条件编译” → `#define`

### 5. 一句话记住

`const` 在 `*` 左边：`*s` 不能改；  
`const` 在 `*` 右边：`s` 不能改；  
两边都有：都不能改。

## 带 `n` 和不带 `n` 的区别

`n` = 最多处理多少个字符/字节。

| 不带 n | 带 n | 区别 |
|---|---|---|
| `strcpy` | `strncpy` | 最多复制 n 个；可能不补 `'\0'` |
| `strcat` | `strncat` | 最多接 n 个；会自动补 `'\0'` |
| `strcmp` | `strncmp` | 最多比较前 n 个字符 |
| `strlen` | 无标准 `strnlen` | `strnlen` 是 POSIX，不是标准 C |
| `strstr` | 无标准 `strnstr` | `strnstr` 不是标准 C |

### 例子

```c
char a[] = "hello world";
char b[6];

strcpy(b, a);      /* 危险：越界 */
strncpy(b, a, 5);  /* 只复制 5 个，b 里没有 '\0' */
b[5] = '\0';       /* 手动补上 */
```

```c
printf("%d\n", strcmp("abc", "abd"));     /* < 0 */
printf("%d\n", strncmp("abc", "abd", 2)); /* 0，前两个字符都是 "ab" */
```

```c
char s[10] = "hi";

strncat(s, " there", 3);   /* 只接 3 个字符 -> "hi th" */
```

### 一句话

- 不带 `n`：一直处理到 `'\0'` 或分出大小为止，**危险在没上限**。
- 带 `n`：最多处理 `n` 个，**安全一点，但有坑**：
  - `strncpy` 可能不补 `'\0'`
  - `strncmp` 只比较前 `n` 个
  - `strncat` 仍要保证 `dst` 空间够

## 现在只要记住

- `strcmp` 返回 `0` 是相等
- `snprintf` 是安全组装字符串
- `strstr` 找不到返回 `NULL`
- `sqrt` 平方根，`pow` 次方，`fabs` 浮点绝对值
