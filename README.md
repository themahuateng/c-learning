## 学习结构：一主线 + 并行线

```
                ┌── 并行线 A：计算机基础（进制 / 补码 / 内存 / 编译）
                │
  主线：C 语言 ──┼── 并行线 B：Python（C 第 10 课后开始）
                │
                └── 并行线 C：数据结构与算法（C 第 14 课后开始）

  贯穿始终：Git / 调试 / 测试 / 文档
```

**为什么并行**：C、Python、数据结构不是三班车。学一个概念时，多处同时用力——
C 里看底层，Python 里看效率，数据结构里看它为什么快、为什么慢。

**上限**：同时最多两条线（C 主线 + 一条并行线），不能三条同时压。

## C 主线：四段能力阶梯

| 段 | 能力目标 | 完成标志 |
|---|---|---|
| 第一段 | 把语言用熟 | 不看书能写分支/循环/数组/函数 |
| 第二段 | 把内存看透 ★当前 | 能画出变量和指针的地址图，说清 malloc 每一步 |
| 第三段 | 把数据组织起来 | 能用结构体和链表组织真实数据 |
| 第四段 | 把程序做完整 | 能独立交付多文件、带文件读写的项目 |

> C 四段只是第一层地基。走完后进入硬件—系统—AI 的长链，见北极星文档。

## 每课的四步练习梯度

```text
基础题：照着骨架填，确认语法会
变式题：改条件、改数量、改类型，确认不是背答案
综合题：不给骨架，自己拆步骤写
验收：关掉资料重写一遍 + 讲给 AI 听
```

只有四步都过，这一课才算完。

## 学习方法建议

1. 每个知识点都要**亲手敲一遍代码**，不要复制粘贴。
2. 主动改代码 → 观察结果 → 思考为什么，这是进步最快的方式。
3. 遇到报错别慌，把报错信息发给我，我帮你分析。
4. 每天 30~60 分钟，比周末突击 5 小时效果更好。
5. **跑通不等于学会**——跑通只到 2 级，关掉资料能写才到 3 级。
6. **被引导写出来的代码要"关卷重写"**，否则只是照抄。
7. 每个阶段末做综合练习，检验掌握程度。
