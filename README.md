## 学习路线图（共 6 个阶段）

### 阶段 1：C 语言入门（第 1–2 周）
- 程序结构、main 函数
- printf / scanf 输入输出
- 变量与数据类型（int、float、char、double）
- 运算符与表达式
- if / else 条件判断、switch 分支
- 练习：简单计算器、判断奇偶数、成绩等级

### 阶段 2：循环与数组（第 3–4 周）
- while / do-while / for 循环
- break / continue
- 一维数组、二维数组
- 字符串基础（char 数组）
- 练习：九九乘法表、猜数字游戏、数组排序

### 阶段 3：函数与模块化（第 5–6 周）
- 函数的定义与调用
- 值传递与参数
- 局部变量 / 全局变量 / static
- 递归
- 练习：汉诺塔、斐波那契数列、模块化学生成绩系统

### 阶段 4：指针与内存（第 7–9 周）★ C 语言的核心
- 指针的概念与用法
- 指针与数组、指针运算
- 动态内存分配 malloc / free
- 指针与函数（指针参数、函数指针）
- 练习：链表、动态数组

### 阶段 5：结构体与文件（第 10–12 周）
- 结构体 struct 与结构体指针
- 文件读写 fopen / fread / fwrite
- 练习：学生信息管理系统（数据存文件）

### 阶段 6：综合项目（第 13 周起）
- 控制台贪吃蛇
- 学生成绩管理系统
- 简易通讯录
- 2048 小游戏

## 学习方法建议
1. 每个知识点都要**亲手敲一遍代码**，不要复制粘贴。
2. 主动改代码 → 观察结果 → 思考为什么，这是进步最快的方式。
3. 遇到报错别慌，把报错信息发给我，我帮你分析。
4. 每天 30–60 分钟，比周末突击 5 小时效果更好。
5. 每个阶段末做综合练习，检验掌握程度。
