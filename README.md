## 学习规则

1. 一次只学一个概念。
2. 跑通不等于掌握：必须能独立写、解释、通过边界测试、做变式。
3. 课件例题是硬清单，不能用“讲过同类概念”代替。
4. 算法题先手算和设计，再编码。
5. 遇到报错先保留现场，再定位，不直接抄答案。
6. 不覆盖已有练习代码；旧版本放进 `04-学习文档\归档\`。

## 整理原则

- 代码留在课程、项目、练习目录。
- 说明文档统一放进 `04-学习文档`。
- 旧版本和备份统一放进 `04-学习文档\归档`。
- 生成物不进入 Git；`.exe` 已在 `.gitignore` 中排除。
