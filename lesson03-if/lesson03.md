# 第 3 课：if 判断（让程序做决定）

## 1. 比较运算符（结果只有 真=1 / 假=0）
| 运算符 | 意思 | 例子 |
|--------|------|------|
| >  | 大于 | 5 > 3 → 1 |
| <  | 小于 | 5 < 3 → 0 |
| >= | 大于等于 | 5 >= 5 → 1 |
| <= | 小于等于 | 5 <= 4 → 0 |
| == | 等于（两个等号！） | 5 == 5 → 1 |
| != | 不等于 | 5 != 4 → 1 |

⚠️ 最容易犯的错：判断相等要写 ==（两个等号），
   一个等号 = 是"赋值"，不是比较！

## 2. if 三种结构
单分支：
    if (条件) { ... }
双分支：
    if (条件) { ... } else { ... }
多分支：
    if (条件1) { ... }
    else if (条件2) { ... }
    else { ... }

执行规则：从上往下找第一个为"真"的分支，执行完就跳过后面所有分支。

## 3. 逻辑运算符
| 运算符 | 意思 | 例子 |
|--------|------|------|
| && | 且（两个都真才真） | hour>=6 && hour<=18 |
| \|\| | 或（一个真就真） | a<0 \|\| a>100 |
| ! | 非（取反） | !(a>b) |

## 4. 取模 %
n % 2 表示 n 除以 2 的余数
- n % 2 == 0 → n 是偶数
- n % 2 == 1 → n 是奇数

## 5. if 后的 { } 可以省略（但强烈建议写）
    if (a > b)
        printf("a bigger\n");   // 只有一行时可以省，但容易出错
    新手阶段：永远写大括号！
