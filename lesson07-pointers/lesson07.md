# 第 7 课：指针（C 的灵魂）

## 1. 指针是什么
变量住在内存里，每格有门牌号（地址）
指针 = 专门装"门牌号"的变量，不是装普通数字的

## 2. 入门四件套（四个符号）
    &a       取地址 —— "a 住在哪"
    int *p   声明一个装地址的指针（星号属于类型）
    *p       解引用 —— 按 p 里的地址去找那一格（星号是运算）
    NULL     空指针，不指向任何地址

**注意**：`int *p` 里的星号 和 `*p = 100` 里的星号是两回事，
前者是"声明类型"，后者是"按地址取/写值"。

## 3. 两条铁律（判断自己写没写对）
    p  ==  &a      // p 里装的地址就是 a 的门牌号
    *p ==  a       // 同一格的两个看法
    *p = 100;      // 顺着 p 改那一格 → a 也跟着变成 100

## 4. 数组名就是首地址
    arr      ≡  &arr[0]
    arr[i]   ≡  *(arr + i)

    指针 + 1 不是"地址加 1 字节"，而是"加一个元素的大小"：
    int * 加 1 → 跳 4 字节；char * 加 1 → 跳 1 字节

## 5. 指针作函数参数（让函数能改外面的变量）
    void add_ten(int *p) { *p = *p + 10; }   // 函数里用 *p 改那一格
    add_ten(&x);                             // 调用时把地址传进去

对比：普通参数是"复印件"，函数里改了不影响外面。
想要函数改外面的变量 → 必须给它地址。

## 6. 命令行参数（main 也能收东西）
    int main(int argc, char *argv[])

    argc  = 收到几个"词"（程序名也算一个，所以最小是 1）
    argv  = 这些词的字符串数组；argv[0] 永远是程序名

只能这样启动才有参数（Ctrl+Shift+B 带不了）：
    .\program.exe apple 20

顺带记住：**递进来的"数字"其实是字符**（"20" 是 '2' 和 '0' 两个字符），
要拿去算数必须自己转换。

## 7. main / return / void（这三个当天一起打通了）
    main 是系统自动调用的函数，你不写 main() 这句调用
    return 的值永远是还给"调用者"的：
        factorial 的 return → 还给 main
        main 的 return 0    → 还给系统

    return 0  = "我正常干完了"；非 0 = "出问题了"
    注意：非 0 不代表死循环，程序照样立刻结束，只是报告内容不同

    void = 空：
        放在函数最前面   → 这个函数不交回值（可以不写 return；
                           写一个光杆 return; 表示提前收工）
        放在参数表 (void) → 不收参数
        写 return 5; 但函数是 void → 编译直接报错

    **地址类型永远是带星号的那种（int * / char *），不是 void。**

## 8. 常见坑
    - scanf 读普通变量要加 &；读字符串 %s 不加
    - 指针没初始化就解引用 → 野指针，程序崩
    - 数组下标从 0 开始，arr[5] 是越界
    - 中文文件名在旧环境会让链接器报错（本机已修好）
