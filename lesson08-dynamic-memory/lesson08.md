# 第 8 课：动态内存（malloc / free）

## 1. 为什么需要它
数组的长度必须写死：
    int a[5];        // 只能是 5 个

如果个数是程序跑起来后才知道的呢？（比如用户输入 n）
→ 动态内存：程序运行中，临时向系统"借"一块内存

## 2. 三个工具
    malloc(字节数)   借一块内存，返回它的首地址
    free(地址)       还回去
    sizeof(类型)     一个类型占几字节

## 3. 标准套路（背下来）
    int *p = malloc(n * sizeof(int));   // 借
    if (p == NULL) { ... }              // 借失败必须检查
    p[i] = ...;                         // 借来的内存当数组用
    free(p);                            // 用完还回去
    p = NULL;                           // 防止继续误用

## 4. 四个关键点
    1. malloc 返回 void *（通用指针），赋给 int * 会自动转换
    2. 借的是"字节数"，所以要 n * sizeof(int)，不是 n
    3. 借了必须还（free），否则内存泄漏
    4. free 之后那块内存就不属于你了，再访问是野指针

## 5. 常见坑
    - 忘了检查 malloc 返回的 NULL
    - free 之后继续用那块内存
    - 同一块内存 free 两次（double free，程序崩）
    - 借了不还（内存泄漏：程序跑久了内存越用越多）

## 6. 相关函数（先知道有，用到再查）
    calloc(n, size)   借 n 个，自动清零
    realloc(p, size)  把原来那块改成新大小

## 7. 实战中撞出来的三个坑（2026-09-21 练习时实测）

### 坑 1：malloc 不清零

借来的内存里是**垃圾**——可能是之前别人用过的旧数据。

实测：把一块内存写满 `111 222 333 444 555`，free 之后立刻再借一块同样大的，
里面**原封不动还是那些旧值**。

看起来是 0 的时候，多半只是碰巧（系统给的是全新的零页）。

**要清零就用 calloc：**

    int *p = calloc(n, sizeof(int));   /* 借 n 个, 自动清零 */

### 坑 2：scanf 会失败，但不报错

- 输入超出 int 范围（比如 `99999999999999999999999999`）→ n 变成了 `-1`
- 没有数据可读时 → scanf 返回失败，变量**保持原样**（可能是没初始化过的垃圾）

所以读完要检查：

    if (scanf("%d", &n) != 1) { ...处理... }     /* 读失败 */
    if (n < 1 || n > 1000)    { ...处理... }     /* 范围不合理 */

### 坑 3：`^` 不是次方

    a ^ b        /* 这是"按位异或", 不是 a 的 b 次方 */

C 语言**没有幂运算符**。要算次方得用 `pow()`（需要 `#include <math.h>`）。

### 附：return 0 与 return 1

    return 0;    /* 交给系统的报告: 一切正常 */
    return 1;    /* 交给系统的报告: 出问题了 */

这个数字叫**退出码**，程序本身照跑不误，是给"调用它的东西"（操作系统、脚本）看的。
**正常路径的最后一行永远是 0**，出错时提前 return 非 0。
