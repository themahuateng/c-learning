# 第 9 课：二维数组（表格）

## 1. 二维数组是什么

一张表格：几行几列。

    int a[3][4];      // 3 行 4 列
    a[0][0]  a[0][1]  a[0][2]  a[0][3]
    a[1][0]  a[1][1]  a[1][2]  a[1][3]
    a[2][0]  a[2][1]  a[2][2]  a[2][3]

第一个下标 = 行，第二个 = 列。**都从 0 开始**：
3 行的合法行号是 0、1、2；4 列的合法列号是 0、1、2、3。

## 2. 初始化

    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};   // 最清楚的写法
    int b[2][3] = {1, 2, 3, 4, 5, 6};       // 效果一样（自动按行填）
    int c[2][3] = {{7}, {8, 9}};            // 没写到的自动补 0

## 3. 遍历（两层循环，背下来）

    for (int i = 0; i < 行数; i++) {
        for (int j = 0; j < 列数; j++) {
            ... a[i][j] ...
        }
    }

外层是行、内层是列，别写反。

## 4. 内存里怎么排（现在知道有这么回事就行）

C 的二维数组是"按行排"的：

    a[0][0] a[0][1] a[0][2] a[1][0] a[1][1] a[1][2] ...

所以 3 行 4 列的 int 数组 = 12 个连续的 int。
用指针看就是 `*(*(a + i) + j)` —— 相当于 `a[i][j]`（第 8 课学的指针运算的延伸）。

## 5. 小补丁 A：switch 多分支

    switch (表达式) {
        case 1:  做点事; break;
        case 2:  做点事; break;
        default: 都不匹配时做点事;
    }

用在"一个值、多种情况"的地方，比一长串 if-else 清楚。

**坑**：忘了写 `break` 会"往下穿透"，把后面 case 的代码也执行了。

## 6. 小补丁 B：条件运算符（三目运算符）

    max = (a > b) ? a : b;

读法：a 大于 b 吗？**是**就取 a，**否**就取 b。
它就是 if-else 的简写版，适合这种很短的选择。

## 7. 常见坑

- 越界：`int a[3][4]` 的最后一个格子是 `a[2][3]`，不是 `a[3][4]`
- 行列写反：声明 `a[2][3]` 却按 3 行 2 列遍历
- 打印时行列数不匹配，矩阵会歪

## 8. 练习

输入一个 2 行 3 列的矩阵，输出它的**转置**（3 行 2 列）。
转置 = 行列互换：原来的 `a[i][j]` 放到结果的 `t[j][i]`。
