# 项目 02：成绩分析器

> 类型：综合练习（复习阶段的大练习）
> 目标：把数组、循环、函数、**数组作函数参数**串起来，做成一个完整可用的小程序
> 状态：待完成（文件夹原本是空的，本任务书是起点）

---

## 一、一句话说清要做什么

输入一批学生成绩，输出一份统计报告。

## 二、功能需求

### 必做

1. 先问"要输入几个成绩"，读入 `n`（假设 1 ≤ n ≤ 100）
2. 读入 `n` 个整数成绩
3. 输出这份报告：
   - 总分
   - 平均分（保留两位小数）
   - 最高分、最低分
   - 及格率（≥ 60 分的比例，用百分比，保留一位小数）
4. **必须用函数实现**，至少三个：
   - 读入成绩
   - 统计（总分 / 平均 / 最高 / 最低 / 及格人数……可以拆成多个小函数）
   - 打印报告
5. 打印要整齐（数字对齐、单位清楚）

### 选做（做完必做再来）

6. 分数段统计：90-100 / 80-89 / 70-79 / 60-69 / <60，各几人
7. 成绩从高到低排序后输出
8. 输入校验：成绩不在 0~100 之间时提示重输
9. 循环模式：统计完一组，问"还要再来一组吗"
10. 动态内存版：用 `malloc` 开数组（学完第 8 课后做）

## 三、用到的已学知识

| 知识 | 用在哪 |
|---|---|
| 数组 | 存 n 个成绩 |
| **数组作函数参数** | 本项目核心：`void read_scores(int a[], int n)` |
| 循环 | 读入、统计、打印 |
| 函数与返回值 | 求总分、找最高分 |
| 浮点与格式符 | 平均分、及格率 |
| 条件判断 | 分段统计、比较大小 |

## 四、函数设计建议（名字可以自己起）

```
void read_scores(int a[], int n);        读入
int  sum_scores (int a[], int n);        总分
int  max_score  (int a[], int n);        最高分
int  min_score  (int a[], int n);        最低分
int  count_pass (int a[], int n);        及格人数
void print_report(int a[], int n);       打印整份报告
```

> 数组参数写成 `int a[]` 就行，不需要写长度——长度另外用 `n` 传进去（这是第 7 课学的）。

## 五、验收标准

- [ ] `gcc -std=c17 -Wall -Wextra` 编译**零警告**
- [ ] 至少 3 个函数；`main` 里主要是"调用"，不是一堆计算堆在一起
- [ ] 三组测试数据全部正确：
  - 全及格：`60 70 80 90 100`
  - 含不及格：`30 50 60 90 100`
  - 边界：一组全是 `0`，一组全是 `100`
- [ ] 用 `Shift + Alt + F` 格式化过
- [ ] 每完成一个功能，做一次 git 提交

## 六、建议的实现顺序（别一次写完）

1. **先写框架**：在 `main` 里把步骤写成注释
2. **读入部分**跑通：能读进 n 个数并原样打印 → 编译 → 测试 → 提交
3. **统计部分**一个一个加（总分 → 平均 → 最高 → 最低 → 及格率），每加一个就测一次
4. **打印部分**再处理格式
5. **最后**处理边界（n=1、全部相同分数）
6. 选做功能一次只加一个
